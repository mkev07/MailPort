# MailPort SDK

Node.js reference implementation of the MailPort account schema, encrypted file format and import adapter contract. MIT licensed.

See the [project README](../../README.md), [draft specification](../../docs/specification.md) and [security model](../../docs/security.md). This package does not require the MailPort desktop application's Tauri/React stack.

From the repository root, run `npm run check --workspace @mailport/sdk`.
